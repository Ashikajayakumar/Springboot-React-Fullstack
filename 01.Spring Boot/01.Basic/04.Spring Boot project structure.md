# 📂 2. `src`

`src` means **source**.

This is where your application source code is stored.

```text id="4h8m2q"
src
├── main
└── test
```

There are two important parts:

```text id="1w6k9p"
main → 💻 actual application

test → 🧪 testing code
```

So:

```text id="r5x8n3"
src
│
├── main     ← 💻 application
│
└── test     ← 🧪 tests
```

---

# 📂 3. `src/main`

This contains the main application.

```text id="2j7q4m"
src
└── main
    ├── ☕ java
    └── 📁 resources
```

There are two important folders:

### ☕ `java`

Contains your Java code.

### 📁 `resources`

Contains configuration and other application resources.

# 🚀 5. Main application class

You will normally have a class similar to:

```java id="3f8k1m"
package com.example.crud;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class CrudApplication {

    public static void main(String[] args) {
        SpringApplication.run(CrudApplication.class, args);
    }
}
```

This is extremely important. ⭐

---

# ▶️ 6. What is `main()`?

You already know Java, so you know:

```java id="0y7v3n"
public static void main(String[] args)
```

is the starting point of a Java application.

In Spring Boot:

```java id="5k2p8r"
public static void main(String[] args) {
    SpringApplication.run(CrudApplication.class, args);
}
```

starts the Spring Boot application.

Think:

```text id="1q6m9x"
▶️ Run application
      ↓
main()
      ↓
SpringApplication.run()
      ↓
🚀 Spring Boot starts
      ↓
📦 Spring Container starts
      ↓
🐱 Embedded Tomcat starts
      ↓
✅ Application ready
```

---

# 🏷️ 7. What is `@SpringBootApplication`?

You will see:

```java id="7c4n2v"
@SpringBootApplication
```

This is one of the most important Spring Boot annotations.

It tells Spring Boot:

> 💡 "This is the main Spring Boot application class."

It enables important Spring Boot features, including configuration and component scanning.

For now, remember:

```text id="2m8x5k"
@SpringBootApplication
        ↓
🚀 Spring Boot application starts/configures
```

# ⚙️ 9. `application.properties`

This file contains application configuration.

For example, you've already worked with configuration like:

```properties id="3m7q5x"
spring.application.name=crud

spring.datasource.url=jdbc:mysql://localhost:3306/crud_db
spring.datasource.username=root
spring.datasource.password=your_password

spring.jpa.hibernate.ddl-auto=update
```

This tells Spring Boot things such as:

```text
🏷️ Application name
       ↓
🗄️ Database URL
       ↓
👤 Database username
       ↓
🔐 Database password
       ↓
⚙️ JPA/Hibernate settings
```

So remember:

> ⚙️ **`application.properties` = configuration/settings of your Spring Boot application.**

You already learned this.

The project structure contains:

> 📄 **`pom.xml` is Maven's configuration file.**

# 📦 14. `target`


For example:

# 🧩 15. `mvnw` and `mvnw.cmd`


# 🔄 17. What does Controller → Service → Repository → Entity mean?

This is the next important concept.

Imagine a student CRUD application.

A user sends:

```text
GET /students
```

The request flows approximately like this:

```text
              👤 Client
                │
                ↓
          🎮 Controller
                │
                ↓
            ⚙️ Service
                │
                ↓
           🗄️ Repository
                │
                ↓
             🐬 MySQL
```

And the data is represented by an:

```text
🏷️ Entity
```

So:

```text
🎮 Controller
    ↓
receives HTTP request

⚙️ Service
    ↓
business logic

🗄️ Repository
    ↓
database communication

🏷️ Entity
    ↓
represents database data
```

# 📦 19. Very important: Package placement

There is one thing you should understand carefully.

Suppose your main class is:

```java id="5m8q2x"
package com.example.crud;
```

and:

```java id="6p3k9v"
@SpringBootApplication
public class CrudApplication {
}
```

Then normally your other Spring components should be placed under that package:

```text id="2x7m4q"
com.example.crud
│
├── CrudApplication
├── controller
├── service
├── repository
└── entity
```

Why?

Because Spring Boot's component scanning normally starts from the package containing the main application class and scans its subpackages.

So this is good:

```text id="9v5k2m"
com.example.crud
│
├── 🚀 CrudApplication.java
├── 🎮 controller
├── ⚙️ service
├── 🗄️ repository
└── 🏷️ entity
```

# ⭐ What you should memorize

Don't try to memorize every folder yet. Remember these **7 things**:

| 📁 File/Folder           | 🎯 Purpose                            |
| ------------------------ | ------------------------------------- |
| `src/main/java`          | ☕ Java application code               |
| `src/main/resources`     | 📁 Configuration/resources            |
| `application.properties` | ⚙️ Application configuration          |
| `src/test`               | 🧪 Test code                          |
| `pom.xml`                | 📦 Maven configuration + dependencies |
| `target`                 | 🔨 Generated build output             |
| `CrudApplication.java`   | 🚀 Main Spring Boot application       |

And later, inside your Java package:

```text
🎮 Controller → handles requests
        ↓
⚙️ Service → business logic
        ↓
🗄️ Repository → database operations
        ↓
🏷️ Entity → data/database model
```
